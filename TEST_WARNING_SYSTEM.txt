## Frontend Shows Warnings:

```

```

### Warning Notice (After Posting):
```

```

```

Your account has been blocked due to multiple violations of community guidelines.
Please contact the administrator for further assistance.
[Return to Login]
```

---

## Backend Flow:

1. User posts intermediate comment
2. Backend:
   - Inserts warning into `warnings` table
   - Increments `warning_count` in `users` table
   - Checks if `warning_count >= 3`
   - If YES → Sets `is_blocked = 1`
   - Returns response with `blocked: true` (if 3rd warning)

3. Frontend:
   - Receives response
   - Shows warning message (if < 3 warnings)
   - Shows blocked overlay (if 3rd warning)

---

## Database Tables:

### users table:
- `warning_count` - Number of warnings
- `is_blocked` - 0 = active, 1 = blocked

### warnings table:
- Records each warning with timestamp
- Columns: `id`, `user_id`, `type`, `content`, `severity`, `created_at`
